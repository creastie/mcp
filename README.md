# Creastie MCP

Сервер [MCP](https://modelcontextprotocol.io/) для Creastie. Подключается к Cursor, Claude Desktop и другим MCP-клиентам, чтобы через ИИ управлять постами, подписками и комментариями — удобно для миграции контента и автоматизации блога.

## Требования

- Node.js 20+
- Аккаунт Creastie
- MCP-токен доступа (выдаётся в Creastie; храните только у себя)

## Установка

```bash
git clone https://github.com/creastie/mcp.git
cd mcp
npm install
npm run build
```

## Настройка Cursor / Claude Desktop

```json
{
  "mcpServers": {
    "creastie": {
      "command": "node",
      "args": ["/absolute/path/to/mcp/dist/index.js"],
      "env": {
        "CREASTIE_API_URL": "https://api.creastie.com",
        "CREASTIE_API_TOKEN": "ваш-токен"
      }
    }
  }
}
```

Путь в `args` замените на абсолютный путь к `dist/index.js` после сборки.  
Токен не вставляйте в промпты — только в env MCP-конфига.

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `CREASTIE_API_URL` | Адрес API Creastie (`https://api.creastie.com`) |
| `CREASTIE_API_TOKEN` | Ваш MCP-токен |

## Что умеет

**Подписки:** список, создание, изменение, удаление  
**Посты:** список, создание, изменение, удаление, публикация, закрепление  
**Комментарии:** список, создание, изменение, удаление, вкл/выкл комментариев у поста  

Повторные создания защищены от дублей (идемпотентность на стороне клиента).

## Права доступа токена

Токен выдаётся с набором прав (scopes). Без нужного права соответствующее действие будет отклонено.

| Право | Что можно делать |
|-------|------------------|
| `mcp` | Полный доступ ко всем MCP-операциям ниже |
| `mcp:posts` | Посты: смотреть свои, создавать, редактировать, удалять, публиковать, закреплять / откреплять; включать и отключать комментарии у поста |
| `mcp:subscriptions` | Платные уровни подписки: смотреть, создавать, менять, удалять |
| `mcp:comments` | Комментарии: смотреть, писать, редактировать, удалять |

**Как это сочетается**

- Если в токене есть `mcp` — остальные scopes не нужны, доступ полный.
- Можно выдать узкий набор, например только `mcp:posts` — тогда ИИ сможет вести блог, но не трогать тарифы подписок и чужие сценарии с комментариями вне постов (операции комментариев требуют `mcp:comments`).
- Несколько прав можно комбинировать: `mcp:posts` + `mcp:comments`.
- Обычный вход в сайт (сессия) этими scopes не ограничивается — они действуют только для MCP-токена.

**Рекомендации**

- Для повседневной автоматизации блога чаще всего достаточно `mcp:posts` (и при необходимости `mcp:comments`).
- `mcp` или `mcp:subscriptions` выдавайте осознанно: изменение тарифов влияет на монетизацию.
- Не используйте один «вечный» полный токен на все машины: лучше отдельный токен на каждое устройство/клиент и отзыв при утечке.
